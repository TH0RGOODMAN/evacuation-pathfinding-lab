# 模型、约定与验证

版本：v0.1.0；验证日期：2026-11-09；本机 Node.js v24.22.1、Chromium。

## 算法约定

18列×12行公开演示网格。纯模块支持2—60列/行；障碍布尔值、风险0—100，起终点必须可通行。演示可调 λ=0—8，模块允许0—100。

只允许四邻接，不走对角线。进入格点v的边代价为1+λr(v)。路径长度为边数，累计风险排除起点、包含到达格点；起终点相同时三个指标均为0。同一格风险只由路线进入计入，不模拟暴露时间。

A*的h为到目标的曼哈顿距离。每步代价至少1，因此h可采纳且一致；关闭节点无需重新开放。打开集合使用线性扫描，适合小网格，未声称大型地图性能。f相同按格点索引打破平局，确保同输入确定性。

λ=0两次搜索完全一致。两张界面卡片的目标代价使用各自λ；要跨路线判断优劣，应按同一λ重新评价。风险区绕不开时最优路线仍可能经过风险格。
